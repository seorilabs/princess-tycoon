# 07. 기능별 인수조건 (Acceptance Criteria)

> 형식: Given(전제) / When(행동) / Then(검증). 각 항목은 자동/수동 테스트의 기준이다.
> 시스템 ID는 `03`, 수치는 `04`와 일치해야 한다. 수치 검증은 "`04`의 값과 동일"로 판정한다.
> ✅ = 필수(MVP), ⭐ = 확장.

---

## AC-NEWGAME (S14 신규 게임) ✅
- **AC-NEWGAME-1** Given 새 게임 시작 / When 아버지·딸 이름과 생일 입력 후 시작 / Then 딸 나이=10, 소지금=`04 §A.1`(3000G), 기본 스탯=`04 §A.2`로 상태가 초기화되고 1년차 시작 월로 진입한다.
- **AC-NEWGAME-2** Given 이름 미입력 / When 시작 시도 / Then 진행이 차단되고 안내가 표시된다.
- **AC-NEWGAME-3** ⭐ Given `astrologyMod=true` / When 생일 선택 / Then 별자리/혈액형 보정이 시작 스탯에 가산된다.

## AC-TIME (S1 시간/캘린더) ✅
- **AC-TIME-1** Given 임의의 월 / When 월간 처리 1회 완료 / Then `month`가 +1되고 12월 다음은 다음 해 1월, `turnIndex` +1이 된다.
- **AC-TIME-2** Given 생일 월 도달 / When 월 진입 / Then 나이가 +1되고 신체검사(EV_BIRTHDAY)가 실행된다.
- **AC-TIME-3** Given `turnIndex`가 96 도달(18세) / When 월 처리 / Then 더 이상 스케줄을 받지 않고 엔딩 판정으로 진입한다.
- **AC-TIME-4** Given 캘린더 고정 이벤트 월 / When 해당 월 진입 / Then `04 §B`의 해당 대회/축제가 트리거된다.

## AC-SCHED (S2 스케줄) ✅
- **AC-SCHED-1** Given 월 시작 / When 카테고리 선택지 표시 / Then 교육·알바·휴식·모험이 모두 노출되고 각 항목의 비용/효과/잠금 사유가 카드에 표시된다.
- **AC-SCHED-2** Given 소지금 < 활동 비용 / When 해당 활동 선택 시도 / Then 선택이 차단(비활성)되고 사유가 표시된다.
- **AC-SCHED-3** Given 개방조건 미충족 활동 / When 카드 표시 / Then 잠금 아이콘과 필요조건이 표시되고 선택 불가하다.
- **AC-SCHED-4** Given 활동 확정 / When 월간 처리 / Then `03 §S2` 파이프라인(비용→스탯→스트레스→도덕→보수→이벤트→클램프) 순서대로 1회만 적용된다.
- **AC-SCHED-5** Given 활동 확정 전 / When 미리보기 / Then 예상 결과(주요 스탯 증감/비용)가 표시되고, 확정 후에는 해당 월 변경이 불가하다.

## AC-STAT (S3 스탯) ✅
- **AC-STAT-1** Given 임의 스탯 변동 / When 적용 / Then 결과값이 `04`의 범위로 클램프된다(하한 0, 상한 스탯별 정의).
- **AC-STAT-2** Given 기본 스탯 변경 / When 파생 스탯 조회 / Then `04 §C` 공식으로 hp/attack/charm 등이 재계산된다.
- **AC-STAT-3** Given 스탯 화면 / When 표시 / Then 4군(기본/전투/기능/누적) 전부 조회 가능하고 전월 대비 증감이 표시된다.

## AC-EDU (S4 교육) ✅
- **AC-EDU-1** Given 수업 X 선택, 소지금 충분 / When 처리 / Then 수업료가 차감되고 주/부 스탯이 `04 §E` × 성장공식(`04 §D`)으로 상승, 스트레스가 가산된다.
- **AC-EDU-2** Given 동일 수업 반복으로 대상 스탯이 softCap 근접 / When 처리 / Then aptitudeMod로 상승폭이 둔화된다(수확체감 확인).
- **AC-EDU-3** Given 상위 수업 개방조건 미충족 / When 선택 / Then 차단된다.

## AC-WORK (S5 아르바이트) ✅
- **AC-WORK-1** Given 직종 Y 선택 / When 처리 / Then 보수가 `wage×performanceMod`로 입금되고 스탯/죄/도덕/평판/스트레스가 `04 §F`대로 변동한다.
- **AC-WORK-2** Given 위험 직종 / When 처리 / Then 사고/부상 확률 판정이 1회 수행되고 발생 시 스탯 손실·특수 이벤트가 적용된다.
- **AC-WORK-3** Given 야간/술집 직종 / When 처리 / Then 죄↑·도덕↓·평판↓가 반드시 함께 적용된다.
- **AC-WORK-4** Given 연령/스탯 개방조건 미충족 직종 / When 선택 / Then 차단된다.

## AC-STRESS (S6 스트레스) ✅
- **AC-STRESS-1** Given 스트레스 구간별 / When 성장 처리 / Then `04 §H`의 stressMod가 성장폭에 곱해진다.
- **AC-STRESS-2** Given 스트레스 ≥60 / When 월말 / Then 반항 이벤트 확률이 발동 가능하다.
- **AC-STRESS-3** Given 휴식/아이템/대화 사용 / When 처리 / Then 스트레스가 `04 §G`/관련 값만큼 감소(하한 0)한다.
- **AC-STRESS-4** Given 스트레스 ≥80이 3개월 누적 & temperament 낮음 / When 판정 / Then EV_RUNAWAY 분기가 가능해진다.

## AC-MORAL (S7 도덕/죄/신앙/평판) ✅
- **AC-MORAL-1** Given 도덕축 변동 행위 / When 처리 / Then `04 §I`의 sin/faith/morals/reputation 변동이 적용된다.
- **AC-MORAL-2** Given faith ≥100 / When 월말 / Then sin이 `floor(faith/100)`만큼 상쇄(하한 0)된다.
- **AC-MORAL-3** Given 평판 임계(예: ≥80 / <30) / When 엔딩/이벤트 게이트 평가 / Then 해당 엔딩/이벤트의 개방/차단이 정확히 반영된다.

## AC-ADV (S8 모험/전투) ✅
- **AC-ADV-1** Given 모험 출발(장비·목적지) / When 진행 / Then 이동일수 소모·인카운터 판정·전투/이벤트가 `03 §S8` 흐름대로 처리된다.
- **AC-ADV-2** Given 전투 / When 명령 입력 / Then 행동순서=agility 내림차순, 피해=`04 §L.3` 공식, MP 소모/명중 판정이 정확히 적용된다.
- **AC-ADV-3** Given 딸 HP 0 / When 전투 패배 / Then 부상 상태(stamina-20)로 강제 귀환하고 사망하지 않는다(특수조건 제외).
- **AC-ADV-4** Given 전투 승리 / When 정산 / Then 전투스탯 경험·골드·드롭이 `04 §L`대로 지급된다.
- **AC-ADV-5** ⭐ Given AREA_DEMON 클리어 / When 귀환 / Then 모험가/영웅 엔딩 플래그가 세팅된다.

## AC-SHOP (S11 상점/장비/의상) ✅
- **AC-SHOP-1** Given 상점, 소지금 충분 / When 품목 구매 / Then 소지금 차감·인벤토리 추가가 되고 판매 시 환급된다.
- **AC-SHOP-2** Given 의상 장착 / When 적용 / Then 포트레이트 레이어가 변경되고 `04 §K.1` 보정이 스탯에 반영된다.
- **AC-SHOP-3** Given 격식 자리(대회/궁정)에 부적합 의상 / When 참가 / Then reputation -5 페널티가 적용된다.
- **AC-SHOP-4** Given 무기/방어구 장착 / When 전투 / Then weaponAtk/armorDef가 파생 스탯에 반영된다.

## AC-CONTEST (S10 대회) ✅
- **AC-CONTEST-1** Given 대회 월 & 참가 선택 / When 채점 / Then 딸 점수=`04 §M` 가중합, NPC 점수=난이도 곡선으로 순위가 산정된다.
- **AC-CONTEST-2** Given 입상(1~3위) / When 정산 / Then 상금·평판이 `04 §M` 보상표대로 지급되고 엔딩 가점 플래그가 누적된다.
- **AC-CONTEST-3** Given 불참 선택 / When 월 진행 / Then 대회가 스킵되고 패널티가 없다.

## AC-EVENT (S9 이벤트) ✅
- **AC-EVENT-1** Given 월말 / When 이벤트 판정 / Then 조건 충족 후보 중 우선순위 1건이 발생(또는 큐잉)한다.
- **AC-EVENT-2** Given 1회성 이벤트가 이미 발생 / When 재판정 / Then 플래그로 재발생하지 않는다.
- **AC-EVENT-3** Given 선택지 이벤트 / When 선택 / Then 분기별 결과(스탯/플래그/소지금/관계)가 `05`대로 적용된다.
- **AC-EVENT-4** Given 조건 이벤트 임계 도달(예: faith≥200) / When 판정 / Then 해당 조건 이벤트가 1회 트리거된다.

## AC-REL (S12 관계) ✅
- **AC-REL-1** Given 부녀 대화 / When 선택 / Then 호감/기질/스트레스가 분기대로 조정된다.
- **AC-REL-2** Given 월말 / When 큐브 보고 / Then 스탯 요약·증감·빌드 힌트가 표시된다.
- **AC-REL-3** ⭐ Given 구혼/연애 조건 충족 / When 진행 / Then 해당 결혼/관계 엔딩 분기가 개방된다.

## AC-MONEY (S12.4 재정) ✅
- **AC-MONEY-1** Given 월말 / When 정산 / Then 생활비(80G)와 용돈이 지출되고 소지금이 음수가 되지 않도록 활동이 사전 차단된다.
- **AC-MONEY-2** Given 용돈 설정 / When 지급 / Then allowanceMood가 `04 §J`대로 변동하고 400G 초과 시 낭비(sin+1)가 적용된다.
- **AC-MONEY-3** Given 수확제(10월) / When 진입 / Then 보너스 골드가 지급된다.

## AC-ENDING (S13 엔딩) ✅
- **AC-ENDING-1** Given 종료 트리거 / When 판정 / Then 하드 플래그 우선 → 카테고리 점수 → 게이트 충족 → 세부 엔딩 순서(`05 §8.1`)로 정확히 1개 엔딩이 결정된다.
- **AC-ENDING-2** Given 모든 게이트 미달 / When 판정 / Then 평민/가업 폴백 엔딩이 나온다.
- **AC-ENDING-3** Given 엔딩 결정 / When 종료 / Then 엔딩 도감에 해금 기록되고 "근접 미달 Top3"가 표시된다.
- **AC-ENDING-4** Given 동일 시드·동일 입력 / When 2회 플레이 / Then 동일 엔딩이 나온다(결정성, 랜덤 시드 고정 시).

## AC-SAVE (저장/로드, 문서 08) ✅
- **AC-SAVE-1** Given 매 월말 / When 자동 저장 / Then 전체 게임 상태가 직렬화되어 저장된다.
- **AC-SAVE-2** Given 저장본 존재 / When 이어하기 / Then 마지막 월 시작 지점이 정확히 복원된다(스탯/소지금/플래그/인벤토리 일치).
- **AC-SAVE-3** Given 구버전 스키마 세이브 / When 로드 / Then 마이그레이션이 적용되어 손실 없이 호환된다.

## AC-UI (비주얼/UX, 문서 02·06) ✅
- **AC-UI-1** Given 세로 1080×1920 / When 허브 표시 / Then 상태바·포트레이트·말풍선·액션 영역이 `02 §6.2`/`06 §3` 배치대로 렌더된다.
- **AC-UI-2** Given 활동 결과 / When 표시 / Then 스탯 증감 플로팅(+12/-3)과 게이지 갱신이 0.5s 내 피드백된다.
- **AC-UI-3** Given 저사양 기기 / When 플레이 / Then 30fps 이상, 월 전환 1s 이내를 만족한다.
