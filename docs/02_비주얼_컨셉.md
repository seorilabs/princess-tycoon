# 02. 비주얼 컨셉

> 원작 화면 사양(320×200, 256색 VGA)과 화면 구성을 역공학으로 재현하고, 모바일 해상도로 리마스터하는 기준.
> 실제 추출 에셋(팔레트/폰트/스프라이트)은 `extract/assets/` 및 `extract/catalog/ASSET_CATALOG.md` 참조.
> 모바일 레이아웃 적응 상세는 `06_모바일_적응설계.md`.

## 1. 아트 디렉션

## 2. 해상도 / 종횡비

| 항목 | 값 |
|------|----|
| 원작 캔버스 | **640 × 480 px, 16색 플레이너(mode 12h)** / 보조 640×200(mode E) — DOSBox 확정 |

## 3. 팔레트 — **16색 확정** (mode 12h 플레이너)

- DOSBox-X 실행 결과 원작은 **16색 플레이너 VGA(mode 12h, 640×480)**를 사용(256색 아님). 따라서 팔레트는 **16색**.
- 추출: `BACK.DAT` 16색 팔레트 → `extract/assets/palette/back_dat_16.{json,png}`. 샘플 `(0,0,0) (140,224,252) (200,176,252) (160,88,252) …` (6bit×4).
- 모바일: 16색 팔레트를 **컬러 키**로 디자인 토큰화(`--color-skin`, `--color-frame` 등, 문서 08). 픽셀-정확 장면별 16색은 DOSBox savestate VGA 파싱으로 확정 가능(문서 01 §8.2, `ASSET_CATALOG.md` §6.1).

## 4. 캐릭터 비주얼 (딸)

### 4.1 구성 — **원작 그리기 함수로 확정**
원작은 딸을 `WWGIRL(mode, 나이, frame, 표정, _, 의상번호, _)`로 그린다(스크립트 해독, `01 §7`). 즉 **캐릭터 = (나이 × 표정 × 의상) 레이어 합성**. 에셋도 이 축으로 분리한다.
- **대형 포트레이트**: 화면 중앙~우측. 본체(`GD.LBX` GIRL) + 얼굴/표정(`F*.LBX`) + 의상(`DD.LBX` 드레스) 합성.
- **연령 단계**: **10~17세 8단계 포트레이트 확정**(스크립트가 `WWGIRL(1,10..17,...)` 직접 호출). 추가로 `정상/병기(전투복)` 두 형태가 각 연령에 존재.
- **본체 변형(확정 메뉴)**: `기본 / 비행 / 병기 / 건강 / 색기` — 상태(전투·컨디션·색기)에 따라 본체 표현 전환.
- **표정 세트**(최소): 평온 / 기쁨 / 슬픔 / 분노 / 놀람 / 피곤(스트레스) / 아픔.
- **의상 레이어**: 평상복 / 정장 / 귀족 / 캐주얼 / 야간 / 전투복(상점 의상과 연동, `04 §K.1`).

### 4.2 표현 규칙
| 상태 | 표현 |
|------|------|
| 스트레스 高 | 피곤 표정 + 어두운 톤 오버레이 |
| 신앙/축복 | 빛 이펙트 |
| 죄 高 | 어두운/요염 표정 변형 |
| 대회/격식 | 해당 의상 강제 미리보기 |
| 부상 | 붕대/창백 표현 |

### 4.3 페이퍼돌 구조 — **원작 에셋으로 확정**
원작 캐릭터 에셋은 정확히 다음으로 분리·합성된다(`ASSET_CATALOG.md` §4):
| 아카이브 | 역할 | 수량(서브이미지) |
|----------|------|-----------------|
| `GD.LBX` | **딸 포트레이트 본체**(GIRL10..17, 연령 10–17세) | 124 (62 그림 + 62 마스크) |
| `DD.LBX` | **드레스/의상 페이퍼돌 레이어**(DR?X10..17) | 204 (102 그림 + 102 마스크) |
| `FA/FC/FE/FG/FO/FP/FQ/FS/FT/FV/FW.LBX` | **얼굴/표정 세트**(캐릭터군별) | 다수 |
| `FM.LBX` | **UI 프레임/창 테두리** | 20 |
| `FX.LBX` | **컷인/이펙트 스프라이트** | 100 |
> 각 그림은 **type-2(그림) + type-3(알파 마스크/그림자)** 페어로 저장 → 모바일에선 PNG 알파 또는 그림+마스크 2레이어로 이관.

### 4.4 스프라이트 시트 규격(모바일 재제작 기준)
- 포트레이트 기본: 720×1280 권장(세로 캔버스 60% 높이). 원작 본체 치수(예: GD 연령별 ~334–400×75–107)를 비율 참고.
- 레이어 분리(원작 구조 계승): `base(GD 연령별 체형) + face(F* 표정) + dress(DD 의상) + fx(FX 이펙트)`.
- 명명: `daughter_<age>_<expr>_<dress>.png` (예: `daughter_15_smile_formal.png`). 원작 연령 인덱스 10–17 그대로 사용.

## 7. 아이콘 / 컴포넌트 시스템

|----------|------|------|
