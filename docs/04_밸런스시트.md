# 04. 밸런스 시트 (수치 단일 원천)

> 본 문서는 게임의 **모든 수치 상수**를 보유한다. 시스템 명세(03)·인수조건(07)·스키마(08)는 여기를 참조한다.
> 표기: 값은 **레퍼런스 밸런스(REF)** — 내부 정합성을 갖춘 즉시 구현 가능한 기준값이다.
> `extract/catalog/`의 역공학 데이터가 확정되면 본 표를 보정한다(보정 대상은 ⟳ 표시). 보정 전에도 이 값만으로 플레이 가능.
> 단위: 골드=`G`, 스탯=정수, 확률=`%`, 스트레스=0–100.

| 파생 | 공식 (REF) |
|------|-----------|
| `hp` | `floor(stamina × 0.5) + 20 + weaponDefBonus` |
| `mp` | `floor(intelligence × 0.4) + magicSkill × 0.2` |
| `attack` | `floor(strength × 1.0) + combatSkill × 0.3 + weaponAtk` |
| `defense` | `floor(stamina × 0.1) + combatSkill × 0.2 + armorDef` |
| `magicAttack` | `floor(intelligence × 0.6) + magicSkill × 0.5 + wandAtk` |
| `magicDefense` | `floor(faith × 0.3 + intelligence × 0.2) + armorMdef` |
| `agility` | `floor(strength × 0.2 + stamina × 0.1) + 10` |
| `charm(표시)` | `floor(refinement × 0.4 + sensitivity × 0.3 + sexAppeal × 0.3) + dressCharmBonus` |

## D. 성장 효율 공식 (S4, S5)

수확체감(로그형). 같은 수업 반복 시 효율 둔화.

```
gain = baseGain
       × seasonMod        // 계절 적합 1.2 / 비적합 0.9 / 기본 1.0
       × aptitudeMod      // = clamp(1.0 - currentStat/softCap, 0.2, 1.0)
       × stressMod        // S6 표 (0.7~1.0)
       × jitter           // U(0.9, 1.1) 랜덤
gain = round(gain)
```
- `softCap` 기본 600 (스탯이 600 근접 시 성장 20%로 둔화). 상위 수업은 softCap 900.
- 음수 변동(기품↓ 등)은 aptitudeMod 미적용(고정 감소).

## M. 대회 채점 (S10)

```
딸 점수 = Σ(평가스탯 × 가중치) + dressBonus + U(-20,20)
NPC 경쟁자 점수 = baseDifficulty(year) × tierFactor
순위 = 점수 내림차순
baseDifficulty(year) = 100 + year × 80   // 연차가 오를수록 강한 경쟁자
```
| 대회 | 평가 스탯(가중) |
|------|----------------|
| 무투대회 | combatSkill×1.0 + strength×0.5 + attack×0.3 |
| 마법대회 | magicSkill×1.0 + intelligence×0.5 |
| 예술/음악제 | art×1.0 + sensitivity×0.6 |
| 미인대회 | charm×0.8 + refinement×0.5 + sexAppeal×0.4 |
| 학예/웅변 | intelligence×0.8 + conversation×0.6 |
| 무용제 | dance×1.0 + sensitivity×0.4 |

보상: 1위 상금 `300+year×100 G`/평판 +10, 2위 `150+year×50`/+6, 3위 `80+year×30`/+3.
