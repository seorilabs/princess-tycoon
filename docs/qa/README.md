- `mobile-390x844.png`: 기준 세로 화면
- `mobile-430x932.png`: 대형 모바일 화면
- `mobile-720x1280.png`: 고해상도 세로 화면
- `result-feedback-390x844.png`: 활동 완료 카드와 능력치 플로팅 피드백
