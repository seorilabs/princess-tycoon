# 09. 빌드 핸드오프 프롬프트 (AI 코딩 에이전트용)

> 이 문서는 `docs/00~08` + `extract/`를 입력으로, **코딩 에이전트가 단계별로 게임을 구현**하도록 지시하는 프롬프트다.
> 각 Phase는 명령/대상파일/테스트/스모크/인수조건을 갖는다. 한 번에 한 Phase만 구현하고 검증 후 다음으로.

---

## 0. 전제 / 스택

- 엔진: **TypeScript + Phaser + Vite**(웹/캐주얼 기준; 스토어 네이티브면 Unity로 치환하되 로직 모듈은 엔진 비의존 유지).
- 원칙: **게임 로직(상태·공식·리듀서)은 순수 TS 모듈**(`src/core/`)로 작성, 엔진/UI는 이를 호출만. → 단위 테스트/결정성 보장.
- 밸런스는 코드가 아닌 `data/*.json`(스키마 `08 §1`). `04`의 표를 그대로 직렬화.
- 모든 랜덤은 `state.seed` 기반 PRNG(결정성, AC-ENDING-4).

## Not Included (전 Phase 공통)
서버/온라인, 실결제·실광고 SDK(훅 인터페이스만), 멀티플레이, 원작 텍스트/아트/음악 원본 사용.

---

## Phase 1 — 코어 루프 / 세이브 (수직 슬라이스)
**목표**: 새 게임 → 매월 스케줄 1택(교육만) → 스탯 변동 → 시간 진행 → 18세 → 폴백 엔딩, 자동저장.
- 대상: `src/core/state.ts`(세이브 스키마 `08 §2`), `src/core/reducer.ts`(`08 §4` 의사코드), `src/core/prng.ts`, `data/config.json`, `data/classes.json`, 최소 UI(허브/스케줄/스탯/엔딩).
- 명령: `pnpm i && pnpm dev` / `pnpm test`
- 테스트: 세이브 라운드트립(AC-SAVE-2), 시간 진행(AC-TIME-1~3), 클램프(AC-STAT-1), 결정성(고정 seed 동일 결과).
- 스모크: 8년 완주 → 엔딩 1개 출력.
- 인수조건: AC-NEWGAME, AC-TIME, AC-SCHED-1/4/5, AC-STAT, AC-EDU-1, AC-SAVE, AC-ENDING-2.

## Phase 2 — 스케줄 전체 / 경제 / 도덕축
**목표**: 알바·휴식 추가, 소지금/생활비/용돈, 스트레스·죄·신앙·평판, 개방조건 잠금.
- 대상: `data/jobs.json` `data/rests.json`, `reducer` 확장(보수/도덕/스트레스/재정), 잠금 UI.
- 테스트: AC-WORK-1~4, AC-STRESS-1~3, AC-MORAL-1~3, AC-MONEY-1~3, AC-SCHED-2/3.
- 스모크: 야간 알바 빌드 → sin↑/평판↓ 확인; 휴식 → 스트레스↓.

## Phase 3 — 상점 / 의상 / 장비 / 대회 / 이벤트
**목표**: 상점·인벤토리·장비/의상(포트레이트 반영), 대회 채점, 이벤트 엔진(정기/조건/랜덤).
- 대상: `data/shop_items.json` `data/contests.json` `data/events.json`, `src/core/events.ts`, `src/core/contest.ts`, 상점/대회 UI.
- 테스트: AC-SHOP-1~4, AC-CONTEST-1~3, AC-EVENT-1~4.
- 스모크: 대회 입상 → 상금/평판; 의상 격식 페널티; 조건 이벤트 트리거.

## Phase 4 — 모험 / 턴제 전투
**목표**: 지역 이동·인카운터·턴제 전투·전리품·부상 귀환.
- 대상: `data/areas.json` `data/enemies.json`, `src/core/adventure.ts` `src/core/battle.ts`, 맵/전투 UI.
- 테스트: AC-ADV-1~5(피해/순서/패배 처리/보상/플래그).
- 스모크: 숲 원정 1회 → 전투 승/패 양 분기.

## Phase 5 — 엔딩 전체 / 도감 / 관계 / 폴리시 훅
**목표**: 70여 엔딩 판정·도감·근접 미달 힌트, 부녀/큐브/구혼 관계, 광고/IAP 훅(플레이스홀더), i18n, 접근성.
- 대상: `data/endings.json`, `src/core/ending.ts`, `src/core/relations.ts`, `src/platform/AdHook.ts`(no-op), `i18n/`.
- 테스트: AC-ENDING-1~4, AC-REL-1~3, AC-UI-1~3.
- 스모크: 대표 빌드 5종(전사/마도/성녀/예술/악) 자동 플레이 → 의도 엔딩 도달(`08 §6`).

## 검증 게이트(모든 Phase 공통)
- `pnpm lint && pnpm typecheck && pnpm test && pnpm build` 통과.
- 데스크탑 + 모바일(1080×1920) 뷰포트에서 비-블랭크·인터랙티브 확인.
- 미검증 영역은 보고서에 명시(완료로 위장 금지).

## 산출 기대
- 오프라인 단독 실행되는 플레이어블 빌드, `data/` 교체만으로 밸런싱 가능, `07` 인수조건 전수 통과.
