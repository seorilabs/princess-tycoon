## 3. 결정성·장기 성장·밸런스

- 같은 seed·초기 상태·정책으로 1,000 slot을 두 번 실행한 상태 해시가 일치했다.
- 세계 티어 10,000에서도 비용·보상·표기와 BigValue가 유효했다.
- 시즌 1, 10,000, 1,000,000의 5단계 라이벌 표본 승률은 40.0~76.7%로 계약 범위 35~80% 안에 있었다.
- 반복 시즌 심사에서 38개 진로 칭호를 얻은 뒤에도 별과 세계 티어가 계속 증가하고 게임이 종료되지 않았다.
- 계약 생성은 진행 중 활동, 예정 도전, 회복, 반복 비용, 스트레스, 관계 상한, modifier를 같은 시즌 타임라인으로 계산한다. 도전 승리 계약은 예정 완료 slot의 런타임과 공유하는 exact jitter, 선행 경기로 도달 가능한 리그 상대 점수, 기본 난이도 floor를 함께 검사한다. 64개 seed/state 행렬과 마지막 슬롯 실제 reducer 반례를 통과했다.

고정 seed `20260714`, 1 slot=1 게임 일 기준 밸런스 결과다.

| 시점 | 완료 활동 | 골드 | 에너지 | 스트레스 | 명성 | 총 능력치 |
|---|---:|---:|---:|---:|---:|---:|
| 1일 | 1 | 2.54K | 88 | 8 | 0 | 936.61 |
| 7일 | 6 | 1.94K | 14 | 54 | 0 | 1,040.62 |
| 30일 | 26 | 327.11 | 36 | 4 | 54 | 1,341.29 |

각 체크포인트는 시간 진행, NaN/INF 부재, 상태 불변식, BigValue 유효성, 활동 정체 없음 조건을 통과했다.

## 4. 실제 모바일 렌더

아래 이미지는 headless dummy가 아니라 Godot GL Compatibility 런타임으로 메인 씬을 8프레임 실제 렌더해 저장했다.

- [390×844 기준 화면](qa/mobile-390x844.png)
- [430×932 대형 모바일](qa/mobile-430x932.png)
- [720×1280 고해상도 세로](qa/mobile-720x1280.png)
- [390×844 활동 결과 피드백](qa/result-feedback-390x844.png)

```bash
$GODOT_BIN --path godot --script res://tests/render_capture.gd -- \
  --size=390x844 --output="$PWD/docs/qa/mobile-390x844.png"
$GODOT_BIN --path godot --script res://tests/render_capture.gd -- \
  --size=430x932 --output="$PWD/docs/qa/mobile-430x932.png"
$GODOT_BIN --path godot --script res://tests/render_capture.gd -- \
  --size=720x1280 --output="$PWD/docs/qa/mobile-720x1280.png"
$GODOT_BIN --path godot --script res://tests/render_capture.gd -- \
  --size=390x844 --result-feedback \
  --output="$PWD/docs/qa/result-feedback-390x844.png"
```

네 명령 모두 `[RENDER] PASS`와 정확한 픽셀 크기를 출력했다. 육안 검사에서 캐릭터, 현재 활동, 원형 진행, 결과 카드, 핵심 CTA, 하단 탭의 잘림·겹침이 없었다. 결과 카드는 390×844 화면의 상단 218px 안에 유지됐다. 720×1280의 좌우 여백은 390×844 논리 화면을 왜곡하지 않는 `keep` 정책의 의도된 pillarbox다.

## 5. Web export

`npm run build:web`은 release export에 성공했다. `build/web/`에 HTML, JavaScript, PCK, WASM, worklet, 아이콘이 생성됐고, Noto Sans KR import 데이터와 모든 core/UI 스크립트가 패키징 로그에서 확인됐다.

주요 산출물:

- `index.html`
- `index.js` 약 308KB
- `index.pck` 약 11MB
- `index.wasm` 약 36MB

`build/`는 재생성 가능한 산출물이므로 Git 추적 대상에서는 제외한다.

## 6. 범위 감사

GDD 1차 구현 범위의 자동 플래너, 온라인/오프라인 진행, 43개 활동, 자동 모험 3노드, 8개 도전, 계약·라이벌·지역·적·보상 절차 생성, 이벤트, 관계, 장비, 시즌 심사, 38개 무한 칭호, v2 저장/복구/마이그레이션, 12개 UI 경로, 절차 아트, 합성 오디오와 플랫폼 포트를 구현했다. 최신 코드와 문서 계약을 독립 재감사한 결과 실제 gameplay 또는 무한 변형 기능 누락은 0건이었다.

의도적으로 제외한 항목은 GDD 범위 경계와 같다: 원작 런타임 리소스, 유료 생성 API, 실제 광고/IAP SDK, 서버·클라우드 저장·멀티플레이, 스토어 출시. 구현 정본과 계약의 1차 범위에서 남은 미구현 항목은 없다.
